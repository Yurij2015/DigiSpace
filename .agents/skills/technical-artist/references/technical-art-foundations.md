# Technical art foundations

These sources informed the skill's technical-art defaults. Use the documentation for the exact engine and version in the project; project conventions and measured results take precedence.

- [Epic: Performance Guidelines for Artists and Designers](https://dev.epicgames.com/documentation/en-us/unreal-engine/performance-guidelines-for-artists-and-designers): practical costs for materials, meshes, UVs, skinning, morph targets, and world-position offset.
- [Epic: Guidelines for Optimizing Rendering for Real-Time in Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine/guidelines-for-optimizing-rendering-for-real-time-in-unreal-engine): versioned guidance for real-time rendering budgets and optimization.
- [Unity: Graphics performance and profiling](https://docs.unity.cn/Manual/graphics-performance-profiling.html): profiling tools and the distinction between rendering costs.
- [Unity: Graphics performance fundamentals](https://docs.unity.cn/Manual/OptimizingGraphicsPerformance.html): draw calls, LOD, textures, lighting, and platform-aware optimization.
- [The Technical Artist: role and disciplines](https://www.thetechnicalartist.com/tech-art/role-of-technical-artist.html): a useful map of shader/material, tools/pipeline, and real-time rendering responsibilities.

These links are references, not copied instruction. Verify APIs, renderer behavior, and performance guidance against the installed engine and target hardware.
